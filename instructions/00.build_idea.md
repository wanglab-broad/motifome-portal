# Online portal of motif association network analysis proposal

In this task, I want to build a online visualization portal for my motif discovery. 
I want to achieve these things below:
1. if the user search a gene / transcript, the portal will show the UTR sequences (5'UTR, 3'UTR) and the highlited motifs. and the protein sequences and the highlighted motifs.
2. for a motif, show their clusters, and how does that motif interact with the protein features. also show the annotations on these motifs. 
3. also have a meta modules showing the interaction between protein modules and RNA modules with the motif concensus. When you click the nodes or edges, show the details of them, including the annotations. 

Please make sure this portal is interactive instead of static figures because we need to visualize a complex project.
